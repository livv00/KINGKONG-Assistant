分组操作

  • Ctrl+C - 复制分组
  • Ctrl+V - 粘贴分组
  • Delete - 删除分组
  • 鼠标左键长按 - 拖动分组上下移动
  • Ctrl+Alt - 快速展开/收缩当前选中分组

音乐操作

  • 空格键 - 播放/暂停
  • Escape - 停止播放
  • 左箭头 - 播放上一首
  • 右箭头 - 播放下一首
  • 上箭头 - 音量+5%
  • 下箭头 - 音量-5%

文件操作

  • Ctrl+N - 新建项目
  • Ctrl+O - 打开项目
  • Ctrl+S - 保存项目
  • Ctrl+Shift+S - 另存为

通用操作

  • Enter - 确认操作
  • Escape - 取消操作

当前音乐快捷键

UDP触发说明

UDP端口

默认UDP端口: 8888

触发格式

  • group:music - 播放指定分组的指定音乐
  • group:music:action - 执行指定操作

操作类型

  • play - 播放音乐
  • pause - 暂停音乐
  • stop - 停止音乐

示例

  • 1:1 - 播放分组1的第一首音乐
  • 2:3:play - 播放分组2的第三首音乐
  • 1:1:stop - 停止播放

测试代码

// Python测试代码
import socket

def send_udp_message(message, port=8888):
    sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    sock.sendto(message.encode(), ('127.0.0.1', port))
    sock.close()

# 播放分组1的第一首音乐
send_udp_message('1:1')

# 播放分组2的第三首音乐
send_udp_message('2:3:play')

# 停止播放
send_udp_message('1:1:stop')
